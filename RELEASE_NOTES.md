# Station Mini Root 0.3.15 — Alice Homebrew 6.0.1 и чистка кода

- После root ставится **Alice Homebrew 6.0.1** вместо 0.5.3. `prepare-homebrew.py` скачивает закреплённый релиз и сверяет SHA-256; исходники Homebrew больше не копируются в этот репозиторий, они живут в своём.
- Всё, что известно о Мини 1 (USB ID, размер раздела, геометрия UBI, пути прошивки), собрано в `station_root/mini1.py`. Белый список проверенных `updater_switcher` и заглушки noupdate вынесен в `station_root/data/known-firmware.json` с пояснением к каждой записи.
- Проверка root по ADB вынесена в `station_root/adb.py`; порты и таймауты названы.
- Разобраны функции с большой вложенностью: проверка OTA, сборка образа, проверка root, окно приложения. Сложность каждой функции не выше 10.
- Код отформатирован ruff; проверка стиля и сложности добавлена в CI.
- Новые README на русском и английском, описание поддерживаемых прошивок — `docs/FIRMWARE.md`.

Поведение при сборке образа и записи не изменилось: те же проверки, тот же порядок отказов. 90 тестов проходят; установка Homebrew 6.0.1 кодом приложения проверена на Станции Мини 1. Готовые EXE / Linux-сборки для этой версии ещё не собраны.

# Station Mini Root 0.3.14 — вариант прошивки Mini 1 от июля 2025

Исправлена остановка «Неизвестная задача обновлений или версия updater_switcher» на проверенной прошивке `1.305.4.16.3237824040.20250721`.

- Добавлен точный SHA-256 второго подтверждённого `updater_switcher`. Бинарники различаются только 20 байтами GNU Build ID; исполняемый код и все остальные байты совпадают.
- Проверки путей, аргументов и отдельной задачи `maind --platformd` сохранены. Неизвестные бинарники по-прежнему останавливают сборку до записи.
- Удаляется только задача OTA. Настройки и порядок запуска голосовой платформы, mediad, telemetry и fluent-bitd сохраняются.
- Журналы, диагностика Windows / WSL и Homebrew 0.5.3 из предыдущего выпуска сохранены.

Проверка: 90 тестов на Windows (один платформенный пропуск) и 90 на Linux; полный образ собран из предоставленного бэкапа офлайн с отдельным тестовым ключом. Сравнены содержимое, типы, права, UID/GID и ссылки неизменяемых файлов, а также все остальные поля launch.json. На физическую колонку при подготовке выпуска образ не записывался. Бэкап и ключи в публикацию не включены.

Если прежняя версия остановилась до записи: закройте её, распакуйте 0.3.14 и повторите «Установить root». Сохраните рабочую папку, ADB-ключ, WSL и бэкапы; восстанавливать систему из-за этой остановки не требуется.

Сборки: Windows x64 и Linux x86_64 (Ubuntu 24.04 / glibc 2.39), исходники и SHA256SUMS.txt.

# Station Mini Root 0.3.13 — журналы и диагностика Windows / WSL

- Добавлены кнопки «Скопировать весь журнал» и «Сохранить журнал». Полный журнал автоматически пишется в папку данных приложения `logs/`, в том числе когда окно показывает только последние строки.
- Исправлено чтение UTF-16 сообщений Windows/WSL, включая потоки, где предупреждение WSL сменяется выводом Linux в UTF-8. В журнале сохраняются команда и код завершения сборщика.
- Установщик WinUSB теперь сохраняет отдельный журнал с текущим драйвером, этапом и точным кодом libwdi. Добавлено ожидание других установок драйверов и подсказка о перезагрузке Windows при неудаче.
- Если патч исходной системы не прошёл проверку, рядом с подготовляемым образом сохраняется `.diagnostics.json`: версия прошивки, хеши launch.json/updater_switcher и результаты сравнения известного профиля. Конфиги аккаунта, Wi-Fi и ADB-ключи не собираются.

**Границы исправления:** неизвестная версия `updater_switcher` по-прежнему останавливает сборку до записи прошивки. Этот выпуск помогает установить различия; новые непроверенные хеши не добавлены. Успешность установки драйвера на ПК пользователей и прошивка физической колонки этим выпуском пока не проверены.

# Station Mini Root 0.3.12

Исправлена остановка «Не найден updatesd в launch.json» на подтверждённой прошивке Mini 1 с updater_switcher.

- Распознаётся точный исследованный переключатель обновлений: пути, аргументы, штатный platformd и SHA-256 бинарника. Другие варианты не принимаются вслепую.
- Удаляется задача OTA; голосовая платформа, mediad и остальные службы сохраняют настройки и порядок запуска. Известные OTA-входы блокируются прежним механизмом.
- Поддержка stock updatesd и прежнего noupdate сохраняется. Добавлены проверки отказа для неизвестного бинарника, изменённых аргументов, отсутствующей основной службы и дополнительных updater-задач.
- В комплекте Homebrew 0.5.3 с доверенными CA и очисткой старого кэша плагинов. Отдельная кнопка обновления только Homebrew по ADB сохранена. AirPlay автоматически не устанавливается.

Проверка выполнена офлайн на предоставленном бэкапе: сборка образа, сохранность остальных файлов, владельцев, прав и ссылок, а также сохранность всех задач запуска, кроме OTA. На физическую колонку агент образ не записывал. Личные ключи, присланные бэкапы и готовые образы прошивки не публикуются.

Если прежняя программа остановилась на проверке OTA до записи: закройте её, скачайте и распакуйте 0.3.12 и снова нажмите «Установить root». Прежние WSL, рабочую папку, ADB-ключ и бэкапы сохраняйте; восстановление бэкапа для этой ошибки не требуется.

Сборки: Windows x64 и Linux x86_64 (Ubuntu 24.04 / glibc 2.39), исходники и SHA256SUMS.txt.
