# Station Mini Root 0.3.9

Исправлена Windows-сборка: в EXE 0.3.8 отсутствовала библиотека libusb, из-за чего установка зависимостей останавливалась после настройки WSL/драйверов. Теперь библиотека включена в приложение. Пользователю не нужно собирать WinUSB-помощник или устанавливать Python.

**Если возникла ошибка «Не найден libusb»:** закройте 0.3.8, скачайте и распакуйте Windows ZIP 0.3.9, запустите новый EXE и повторите «Установить зависимости». Ранее установленные WSL/ADB, ключи и бэкапы сохраняются. По показанному журналу сбой 0.3.8 происходил до начала прошивки.

- Сборка останавливается до PyInstaller, если USB runtime отсутствует или не загружается.
- Проверяется наличие и SHA-256 libusb внутри готового Windows/Linux файла, затем запускается самопроверка именно собранного приложения.
- Добавлена диагностика `StationMiniRoot.exe --check-usb usb-report.json` (Linux: `./StationMiniRoot --check-usb usb-report.json`). Она только загружает библиотеку, без перечисления/открытия USB-устройств и без команд колонке.
- Сохранены бэкап, восстановление, проверка root и автоматическая установка Homebrew 0.4.1. Алгоритм прошивки не менялся.

Windows x64 и Linux x86_64 (Ubuntu 24.04 / glibc 2.39). Скачайте архив своей ОС, распакуйте и запустите приложение. Исходники и SHA256SUMS приложены. Личные ключи и дампы прошивки не включены.
