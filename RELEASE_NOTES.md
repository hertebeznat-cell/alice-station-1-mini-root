# Station Mini Root 0.3.8

Первый публичный релиз для Яндекс Станции Мини 1 (YNDX-0004, Amlogic A113X).

- Windows x64 и Linux x86_64, интерфейс RU/EN.
- Автоматическая подготовка ADB, WSL/Linux-сборщика и USB-драйверов/udev.
- Бэкап system, сборка из своего бэкапа, установка ADB root, полное обратное чтение и проверка результата.
- Блокировка распознанных штатных OTA-путей и восстановление исходного system из бэкапа.
- Автоматическая установка Homebrew 0.4.1 после проверки root, его автозапуск и последующие обновления менеджера с GitHub раз в 5 часов.
- Штатная Алиса и прочие приложения не отключаются/не удаляются. AirPlay и другие плагины ставятся отдельно.

Скачайте Windows ZIP или Linux tar.gz, распакуйте и запустите приложение. Linux-бинарник требует окружение уровня Ubuntu 24.04 / glibc 2.39; для старых систем используйте исходники. Сохраните рабочую папку с личным ключом, исходным system и session.json. Готовые прошивки, личные данные и ключи в релиз не включены.
