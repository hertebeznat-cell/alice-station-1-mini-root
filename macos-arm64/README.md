# Station Mini 1 for macOS ARM64

Установка USB ADB root, Alice Homebrew, AirPlay и Spotify Connect на Яндекс Станцию Мини первого поколения **YNDX-0004**. Запускается из Терминала Mac с Apple Silicon. USB работает напрямую через IOKit. Docker Desktop запускает Linux ARM64 только для сборки образа. Колонка в Docker не пробрасывается.

## Перед началом

Проверьте модель на наклейке. Подключите Mac к питанию, подготовьте USB-кабель с передачей данных и разблокируйте Mac. Если macOS спросит про подключение аксессуара, нажмите «Разрешить». USB-загрузчик `1b8e:c003` появляется ненадолго сразу после подключения. Подключайте кабель после приглашения программы, без зажатых кнопок.

Понадобятся Command Line Tools, ADB, Python 3 и запущенный Docker Desktop. Если ADB и Python уже установлены, используйте их.

```sh
xcode-select --install
brew install android-platform-tools python
brew install --cask docker-desktop
```

## Запуск

Из корня форка:

```sh
cd macos-arm64
./mini.sh all
```

Скрипт просит сверить модель, читает 80 МиБ исходного `system`, собирает образ с вашим ADB-ключом и известным патчем OTA, затем просит снова подключить USB. Перед записью SHA-256 текущего раздела должен совпасть с бэкапом. После записи считываются все 80 МиБ и сравнивается SHA-256. При совпадении скрипт перезагружает колонку и проверяет `uid=0(root)` по USB. Оставьте питание и кабель подключёнными до окончания записи и обратного чтения. Ключ Spotify вводится в конце, скрыто.

Можно пройти те же шаги отдельно. Если один шаг прервался, запустите нужную команду повторно. Бэкап и образ сохраняются между запусками. Если ADB root уже подтверждён, продолжите с команды `homebrew`.

```sh
./mini.sh probe
./mini.sh backup
./mini.sh build
./mini.sh flash
./mini.sh homebrew
./mini.sh airplay
./mini.sh spotify
./mini.sh status
```

- `probe` читает только ответ IDENTIFY загрузчика. Отдельный запуск перед `all` необязателен.
- Бэкап, SHA-256, образ, отчёт сборки и ADB-ключ лежат в `~/Library/Application Support/Station Mini macOS`. Для второй колонки используйте отдельный каталог через `MINI_SESSION` и сохраните копию рабочего каталога в надёжном месте.
- Сборщик останавливается на неизвестной разметке или схеме OTA. Готовый образ собирается под конкретную колонку из её исходного раздела. OTA отключаются патчем.
- Если ADB после перезагрузки не видит колонку, разрешите новый аксессуар macOS. По умолчанию используется локальный сервер ADB на порту 5038. Если запущенный сервер ADB уже держит USB-интерфейс колонки и он авторизован нужным ключом, запустите команду с `MINI_ADB_PORT=5037`. Для повторной проверки используйте `status`.
- Homebrew 6.0.1 устанавливает YAM v2 при первом запуске. Для этого колонке нужен доступ к интернету. Если YAM ещё отсутствует, проверьте «Станция → YAM» в панели Homebrew и повторите `spotify` после инициализации.

## Пользование

| Функция | Где открыть |
| --- | --- |
| Alice Homebrew | `http://IP-КОЛОНКИ:8088` в доверенной Wi‑Fi-сети. IP покажет `./mini.sh status`. |
| AirPlay | «Пункт управления → Звук/AirPlay → Alice Mini» на Mac или iPhone в той же сети. |
| Spotify Connect | «Подключиться к устройству → Alice Mini Spotify» в приложении Spotify. |

Для первоначальной настройки Spotify создайте ключ в [Spotify Soloist](https://developer.spotify.com/dashboard/soloist) под аккаунтом с Premium и введите в Терминале по запросу `spotify`. Храните ключ приватно. Установщик использует `horohi/soloist` 1.3.12 для `yandexmini` и включает регулировку громкости из Spotify. Голосовой мост Horohi, синхронизация громкости и эффекты этого моста отключаются. Если звук тихий даже при высоком значении Spotify, поднимите общий уровень колонки командой «Алиса, громкость 7». Первая установка требует около 50 МиБ свободного места на разделе `/data`. Если там уже установлен другой Spotify-клиент, сначала сохраните его настройки и освободите место. После переустановки или обновления пакета повторите `spotify`, чтобы заново применить настройку громкости.

## Откат

`./mini.sh restore` возвращает исходный `system`, после полного сохранения текущего раздела в отдельную папку `before-restore.*`. Используйте этот режим только с исходным бэкапом той же колонки. Штатные службы могут изменить содержимое раздела при работе, поэтому откат проверяет размер и SHA-256 файла бэкапа, а после записи сверяет все прочитанные байты с ним. Перед откатом при необходимости остановите или удалите установленные приложения на колонке. Установленные файлы приложений живут в `/data` и могут сохраниться после отката раздела. Если запись прервалась, сохраните питание и USB. Если загрузчик не может целиком прочитать текущий раздел, скрипт остановится до записи. Для восстановления в таком случае используйте сохранённый оригинал и процедуру [Station Mini Root](https://hackalice.me/start/root-mini1-usb/#restore).

## Исходники и публикация

Сценарий для macOS находится в каталоге `macos-arm64` форка [Station Mini Root](https://github.com/uhohhp/alice-station-1-mini-root-macos). Оригинальные файлы приложения Station Mini Root имеют отдельные условия. Скрипт скачивает закреплённую версию сборщика локально для личного использования. Лицензия MIT в этом каталоге относится к скриптам-обёрткам и USB-транспорту с указанной атрибуцией. Пакеты для колонки скачиваются по версиям с проверкой SHA-256.

- [Гайд для Mini 1 по USB](https://hackalice.me/start/root-mini1-usb/)
- [Station Mini Root 0.3.15 и его лицензия](https://github.com/hertebeznat-cell/alice-station-1-mini-root/blob/v0.3.15/LICENSE)
- [Alice Homebrew 6.0.1](https://github.com/hertebeznat-cell/alice-homebrew/releases/tag/v6.0.1)
- [Station AirPlay 0.2.3](https://github.com/skrashevich/station-airplay/releases/tag/v0.2.3)
- [Horohi Soloist 1.3.12](https://github.com/Horohi/soloist-station-lite/releases/tag/v1.3.12)

Прямое чтение, запись, обратная сверка, ADB root и плагины проверялись по шагам на MacBook Air M2 и YNDX-0004. GitHub Actions проверяет синтаксис и сборку USB-утилиты. Единый сценарий `all` на второй чистой колонке пока не прогонялся.
