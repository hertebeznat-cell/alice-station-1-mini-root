# Музыкальное кольцо / Music Ring 1.0.0-beta.1

Экспериментальный нативный плагин Mini 1. Нужны **Homebrew 0.5.0** и **AirPlay 1.0.0-beta.2**. Версия собрана и опубликована по запросу владельца без запуска тестов или установки на колонку.

1. Обновите Homebrew, затем обновите AirPlay из официального магазина и включите его.
2. Установите и включите «Музыкальное кольцо». Другой плагин `led.ring`, например Ring Studio, должен быть выключен.
3. Включите музыку с iPhone через AirPlay. Справа появятся живые показатели звука и кольцо.
4. Выберите спектр, пульс или бегущий свет; настройте два цвета, яркость, чувствительность и плавность, затем сохраните.

В паузах кольцо гаснет; можно включить мягкое свечение. Измеряется только декодированный PCM, который обновлённый AirPlay передаёт в ALSA. Звук не записывается, микрофон не открывается. Передаются только RMS, peak и 12 полос частот, локально на 127.0.0.1:18789. Для других проигрывателей нужен такой же audio meter; автоматически все звуки системы пока не перехватываются.

## Build

`CGO_ENABLED=0 GOOS=linux GOARCH=arm64 go build -tags=musicring -trimpath -ldflags="-s -w" -o plugins/music-ring/plugin.elf ./plugins/music-ring/service`

Затем `alice-homebrew pack plugins/music-ring music-ring-1.0.0-beta.1.aliceplugin`. Нативный код имеет полный root-доступ; реальные операции ограничены чтением конфигурации/локальных уровней звука и передачей LED-кадров менеджеру. Сам плагин не пишет в I²C. LED-кадр отправляется строкой `@alice-ring BASE64`, 36 байт BGR, только при разрешении `led.ring`.
