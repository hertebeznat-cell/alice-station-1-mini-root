# Alice Homebrew 0.4.1

Исправлено отображение версии в блоке обновлений: более старый релиз GitHub больше не выглядит предложением понизить установленную версию. Само понижение было запрещено и в 0.4.0.

Включает автоматическую проверку и установку новых стабильных версий каждые 5 часов, сохранение расписания/плагинов/конфигов, проверку SHA-256 и откат при отказе запуска. Подробнее — docs/MANAGER_UPDATES.md. AirPlay и другие плагины этим обновлением не устанавливаются.
