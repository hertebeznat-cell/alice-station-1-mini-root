# Alice Homebrew 0.5.1

- В магазине показана одна актуальная версия каждого плагина на источник. Старый AirPlay beta.1 убран из текущего официального каталога; актуальная версия — beta.2. Установленные старые версии не отзываются и не удаляются с колонки.
- В «Моих плагинах», настройках плагина и магазине появилась кнопка «Обновить» с доступной версией.
- Обновление берётся из исходного доверенного источника, сохраняет конфиг, состояние включения и предыдущую версию для отката. Запущенный плагин перезапускается; выключенный остаётся выключенным.
- При прежних разрешениях повторное подтверждение не требуется; новые права подтверждаются отдельно. Подпись каталога и целостность пакета проверяются прежним механизмом установки.
- Сравнение версий учитывает beta.2 / beta.10 и стабильные версии. Каталоги разных авторов остаются отдельными источниками.

Чтобы обновить Homebrew из панели: Настройки → Обновления менеджера → Проверить сейчас. После перезапуска обновите страницу. Для плагинов нажмите «Обновить каталог», затем «Обновить» у нужного плагина.

По просьбе владельца выполнены только сборка и публикация: тесты и ручная установка на колонку не выполнялись.
