# Alice Homebrew 0.5.3

Исправлено накопление распакованных исполняемых файлов старых версий плагинов, из-за которого AirPlay после обновления занимал лишнее место.

- Очистка выполняется автоматически при запуске менеджера и после установки, обновления или отката плагина. Для уже установленных плагинов достаточно обновить Homebrew.
- Сохраняются рабочие файлы текущей версии, настройки, пользовательские данные и архив предыдущей версии для отката. При откате исполняемый файл создаётся заново из проверенного пакета.
- Удаляются только каталоги версий с SHA-256 внутри служебной папки runtimes. Символические ссылки и посторонние каталоги пропускаются.
- Пакеты AirPlay и «Музыкальное кольцо» остаются прежних версий. Повторная установка плагинов или получение root не нужны.

Размер в интерфейсе показывает суммарное место на диске, включая распакованные файлы и точку отката. Поэтому он остаётся больше размера скачиваемого .aliceplugin.

Сборки: Windows AMD64, Linux AMD64 и Linux ARM64 для колонки. Проверки и ограничения выпуска описаны в VALIDATION-0.5.3.md. Прямая установка на физическую колонку при подготовке релиза не выполнялась.
