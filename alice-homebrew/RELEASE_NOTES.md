# Alice Homebrew 0.5.2

Исправлен `x509: certificate signed by unknown authority` на прошивках без подходящего системного хранилища CA.

- В менеджер встроен неизменённый Mozilla CA bundle, опубликованный curl. Он дополняет системные корни для каталога, загрузок плагинов и автообновления.
- TLS, имя сервера, срок действия сертификата, подписи каталога и SHA-256 пакетов проверяются по-прежнему. Непроверенный HTTPS или HTTP-обход не используются.
- Никакие сертификаты не записываются в системный раздел колонки. Плагины, конфиги и существующие источники сохраняются.

Если старый Homebrew из-за этой же ошибки не может скачать обновление, скачайте Station Mini Root 0.3.11 на прежний ПК, подключите колонку в обычном режиме ADB и нажмите **«Обновить только Homebrew (ADB root)»**. Не выбирайте повторную прошивку или восстановление бэкапа. Нужна прежняя рабочая папка с авторизованным ADB-ключом. Это установка только сервиса, без чтения/записи образа system.

Проверка с набором CA без системных корней: каталог raw.githubusercontent.com и GitHub API отвечают HTTPS 200 с проверенной цепочкой. Отдельные локальные TLS-сценарии проверяют принятие доверенного CA и отказ при неизвестном CA, неверном hostname и истёкшем сертификате. Полная регрессия Homebrew и установка на физическую колонку для выпуска не выполнялись.

Источник CA: https://curl.se/docs/caextract.html. Лицензия PEM-файла — MPL-2.0; полный исходный bundle, происхождение и SHA-256 находятся в internal/homebrew/certs/, текст лицензии — licenses/mozilla-ca/.
